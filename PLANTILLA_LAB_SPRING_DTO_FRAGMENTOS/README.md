# Plantilla Lab Spring - DTO + Fragmentos Thymeleaf

Plantilla de práctica basada en los temas de clase:

- Spring Web
- Thymeleaf
- Spring Data JPA
- SQL Server
- DTO por Projection
- `@Query(..., nativeQuery = true)`
- Fragmentos Thymeleaf

## Uso

1. Ejecutar `database/script.sql` en SQL Server.
2. Cambiar `TU_USUARIO` y `TU_PASSWORD` en `application.properties`.
3. Ejecutar `PlantillaLabApplication`.
4. Abrir `/employees/estadistica`.
5. Revisar `EXPLICACION_PASO_A_PASO.txt`.

Cuando llegue el laboratorio real, esta plantilla se adapta exactamente a lo que pida el enunciado.
